# EdgeBox：给人看的准备指南，给 AI 用的部署 Skill

项目的作用、原理和资费，先看作者写的 [给人看的说明](HUMAN-GUIDE.zh-CN.md)。

这个仓库放人类说明、提示词和 AI Skill。现有代码另行保留；AI 生成的实现放在使用者自己的私人目录。

## 人类先看这里

阅读 [准备与摆放指南](HUMAN-GUIDE.zh-CN.md)，选购、价格和经验内容由作者在 [作者填写区](AUTHOR-NOTES.zh-CN.md) 定稿。两部分分别说明：

- 哪些东西必须有，哪些已有就不用再买；
- VPS 需要满足的技术条件，以及由作者填写的厂商、套餐、价格与预算；
- 小盒放哪里，电脑和手机放哪里，网线怎样连接；
- 从哪里找 VPS IP、小盒 IP 和 SSH 登录权限；
- AI 能完成什么、哪些步骤需要你在现实世界中操作。

作者也可以亲自写项目介绍、适用人群、购买理由和使用心得。AI 默认保留这些文字，
只在被要求时帮助润色或核验；标为“作者待填写”的地方不会由 AI 自动补推荐或报价。

## 然后把任务交给 AI

**不支持 Skill 的 AI：** 复制 [通用启动提示词](START-PROMPT.zh-CN.md)，并把本仓库文件夹提供给它读取。
该提示词也能单独粘贴使用，但提供完整 Skill 及其引用文件能保留更详细的部署和验收要求。

**支持 Skill 的 AI：** 把整个 [skills/edgebox-deploy](https://github.com/acejunnan/edgebox-skills/tree/main/skills/edgebox-deploy) 文件夹导入该工具支持的 Skill 位置，
保留 `SKILL.md`、`agents/` 和 `references/` 的相对路径。不同工具的导入位置按各自文档确认。
然后输入：

```text
使用 $edgebox-deploy，先检查我的准备情况和两端现状，完成只读预检并给出部署计划。
不要购买服务器，不要改动线上网络。缺少信息时集中问我。
```

准备好并审阅具体计划后，再明确授权：

```text
我授权按刚才确认的计划，在指定 VPS 和小盒上部署 EdgeBox。
按 Skill 保留独立反向 SSH、预置自动回退，并在真实出口和新建管理登录验证通过后提交。
```

VPS IP、小盒 IP、账号及密钥路径应在私人会话中提供；密码和私钥使用工具的安全输入方式，
不要写进 GitHub 仓库。IP 地址不能代替 SSH 登录权限。

## 本仓库的交付方式

- 人负责购买、付款、供电、接网线和确认主机身份。
- AI 负责预检、生成适合当前机器的实现、测试、部署和验收；无远端工具时只生成可审阅的本地产物。
- 新实现保存在用户指定的私人工作目录，本仓库保持文档与 Skill 形式。
- 仅授权部署不等于授权公开代码、凭证、网络地址或诊断报告。
- 现有源码仓库 [acejunnan/edgebox](https://github.com/acejunnan/edgebox) 保留，本仓库不要求使用其中的安装器或历史脚本。

Skill 为新部署提供可执行的工作约束，并不保证任意 AI、设备、运营商网络都能一次部署成功。
验收记录必须区分静态检查、模拟测试、实机测试与尚未验证项。
